Este repositorio contiene el código fuente de mi portafolio profesional, diseñado con arquitectura de alto rendimiento para ofrecer servicios integrales de desarrollo web (Landing Pages, Sitios Corporativos, E-commerce) y soporte informático profesional para Pymes y particulares en Chile.

## 🛠️ Tech Stack & Herramientas
* **Frontend:** HTML5, CSS3 (Bootstrap 5.3), JavaScript ES6+.
* **E-commerce:** WordPress + WooCommerce (integración para tiendas autogestionables sin comisiones SaaS).
* **Herramientas de Construcción:** Vite (entorno de desarrollo y bundling rápido).
* **Integraciones & Seguridad:** EmailJS (envío seguro de formularios), Google reCAPTCHA v2 (protección anti-spam) y pasarelas de pago (Mercado Pago / Flow).
* **Despliegue & Hosting:** CI/CD automatizado mediante Netlify vinculado a GitHub.

## ✨ Características y Secciones del Proyecto
- **Planes de Desarrollo Web de Alta Conversión:**
  - *Landing Page (One-Page):* Diseñada minuciosamente como embudo de ventas rápido.
  - *Sitio Corporativo (Multipágina):* Arquitectura de información para posicionar marcas y empresas.

## ⚙️ Configuración Local
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`.
3. Configurar variables de entorno: Crear un archivo `.env` con las siguientes llaves (excluidas del repositorio por seguridad):
   ```env
   EMAILJS_SERVICE_ID=tu_service_id
   EMAILJS_TEMPLATE_ID=tu_template_id
   EMAILJS_PUBLIC_KEY=tu_public_key
   EMAILJS_PRIVATE_KEY=tu_private_key
   RECAPTCHA_SITE_KEY=tu_site_key
   ```
4. Ejecutar en modo desarrollo: `npm run dev`.
5. Desplegar: El proyecto se despliega automáticamente a Netlify al hacer push al repositorio. Cada actualización enviada a la rama principal activa un build automático en Netlify.
